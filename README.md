Eidolon 是一款轻量、简洁且美观的 Astro 主题。基于 MIT License 开源。 

[GitHub](https://github.com/virelyx258/Astro-Theme-Eidolon) | [云仓](https://src.luming.cool/riseforever2026/Eidolon)

两个仓库互为镜像关系，同步更新。

本主题的设计思想参照了 Typecho 主题 [Mirages](https://get233.com/archives/mirages-intro.html)。

我自己曾是 Mirages 主题用户，后为追求极致速度，便产生了移植主题到 Astro 的想法。

一款外观相似、免费的主题，如果开源，可能会对原付费主题的销售造成影响。但细想想，我们其实不在一个赛道。喜欢使用 Typecho 博客系统、追求简约的用户，一定还会选择 Mirages 的。本主题的开源，只是为 Astro 用户提供另一种选择。

特点：

- 美观、简洁、耐看；
- 页面自适应，根据屏幕大小判断显示顶栏或侧栏；
- 完美支持 Pjax 无刷新加载；
- 支持用户前端深浅色模式切换、字体切换、字体大小调整等功能；
- 支持 LaTeX 数学公式解析；
- 支持多样的短代码；
- 原生支持友链卡片。

欢迎使用。如果能帮助到你，欢迎去 [GitHub 仓库](https://github.com/virelyx258/Astro-Theme-Eidolon) 给我点个 Star。
